# DeFogger

A simple map addon for World of Warcraft: Wrath of the Lich King v3.3.5a

## Installation
Option A: Click the green "Code" button and download the zip file.
Then, extract the folder to your AddOns folder, and remove the "-main" portion of the folder name.

Option B: Go to the "Releases" page and download the latest DeFogger.zip file and extract it to your Addons folder.

## Settings

`/df` or `/defogger` to show the settings

## Features

- Clear map fog
- Zone levels
- Fishing levels
- Player and Cursor Coordinates on the main map
